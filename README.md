# AGV_System_dev

AGV의 새로운 메타나 관련 기술을 적용하고, 공부할 코드를 분석하며 학습 내용을 기록하는 저장소입니다.

## 프로젝트 포트폴리오

- [자동화 가습 AMR](projects/automated-humidification-amr/README.md) — 실내 습도 측정, Nav2 자율주행, 모터 제어와 도킹 검증

| 01 | 메카넘 휠 역기구학 | [한국어 학습 노트](docs/01_mecanum_inverse_kinematics/README.md) | [C++ 예제](examples/01_mecanum_inverse_kinematics/main.cpp) |

## 학습 방법

1. 학습 노트에서 목적, 변수, 단위와 가정을 확인합니다.
2. 코드를 읽고 직접 빌드하여 실행합니다.
3. 입력값을 바꾸며 결과를 예상하고 비교합니다.
4. 실습 결과와 추가로 궁금한 내용을 기록합니다.

예제별 실행 방법과 검증 범위는 해당 학습 노트에 기록합니다.
