# 01. 메카넘 휠 역기구학: 로봇 속도를 바퀴 RPM으로 변환하기

## 학습 목표

로봇의 전후·좌우 이동 속도와 회전 각속도로부터 네 바퀴의 목표 RPM을 계산한다.
역기구학은 원하는 차체 움직임을 만들기 위해 각 바퀴를 얼마나 돌려야 하는지 구하는 과정이다.

- [실습 코드](../../examples/01_mecanum_inverse_kinematics/main.cpp)
- 계산만 수행하는 예제이며 실제 모터 드라이버에 명령을 보내지는 않는다.

## 좌표계와 바퀴 이름

이 예제는 x축 전방, y축 좌측, z축 위쪽을 양의 방향으로 두며,
양의 wz는 위에서 내려다볼 때 반시계 방향 회전이다.

```text
          전방 (+x)
       FL        FR
       RL        RR
```

FL/FR은 앞 왼쪽/앞 오른쪽, RL/RR은 뒤 왼쪽/뒤 오른쪽이다.
바퀴 속도의 양수는 각 바퀴가 차체를 전진시키는 회전 방향을 뜻한다.
실제 모터의 부호는 장착 방향에 맞춰 변환해야 한다.

## 입력값

| 변수 | 의미 | 예제 값 | 단위 |
|---|---|---:|---|
| vx | 전후 이동 속도 | 0.5 | m/s |
| vy | 좌우 이동 속도 | 0.2 | m/s |
| wz | 차체 회전 각속도 | 0.3 | rad/s |
| r | 바퀴 반지름 | 0.1 | m |
| Lx | 차체 중심에서 바퀴 중심까지 전후 거리 | 0.5 | m |
| Ly | 차체 중심에서 바퀴 중심까지 좌우 거리 | 0.5 | m |

Lx와 Ly는 바퀴 중심 기준 전후 간격과 좌우 간격의 절반이다. 전체 길이·폭을 그대로 넣지 않는다.
L = Lx + Ly = 1.0 m이다.

## 계산 흐름

1. 원하는 차체 속도 vx, vy, wz를 정한다.
2. 차체 크기와 바퀴 반지름을 읽는다.
3. 역기구학으로 각 바퀴 각속도(rad/s)를 계산한다.
4. 각속도를 RPM으로 변환한다.
5. 결과를 화면에 출력한다.

```cpp
w_fl = (vx - vy - L * wz) / r;
w_fr = (vx + vy + L * wz) / r;
w_rl = (vx + vy - L * wz) / r;
w_rr = (vx - vy + L * wz) / r;
```

vx, vy, L*wz는 모두 m/s 단위이다. 이를 r(m)로 나누면 바퀴 각속도(rad/s)가 된다.
각 항은 전후 이동, 좌우 이동, 회전에 필요한 바퀴 속도의 기여이다.

이 부호 조합은 특정 메카넘 롤러 배치를 전제로 한다. 실제 장비에 적용하기 전에는
롤러 방향, 바퀴 순서, 좌표계, 모터의 양의 방향이 이 식과 일치하는지 확인해야 한다.
학습 모델은 바퀴 미끄러짐과 변형을 무시한다.

## RPM 변환과 결과

한 바퀴는 2π rad, 1분은 60초이므로:

```text
RPM = 각속도(rad/s) × 60 / (2π)
```

| 바퀴 | 각속도 계산 | 각속도(rad/s) | RPM(약) |
|---|---|---:|---:|
| FL | (0.5 - 0.2 - 0.3) / 0.1 | 0 | 0.000 |
| FR | (0.5 + 0.2 + 0.3) / 0.1 | 10 | 95.493 |
| RL | (0.5 + 0.2 - 0.3) / 0.1 | 4 | 38.197 |
| RR | (0.5 - 0.2 + 0.3) / 0.1 | 6 | 57.296 |

FL에서는 이동과 회전의 기여가 상쇄된다. 부동소수점 오차 때문에 FL은
아주 작은 음수가 될 수 있으며, 출력 형식에 따라 -0.000으로 보일 수 있다.

## 빌드 및 실행

C++11 이상을 지원하는 컴파일러가 필요하다. 저장소 루트에서 실행한다.

```sh
g++ -std=c++11 -Wall -Wextra -pedantic examples/01_mecanum_inverse_kinematics/main.cpp -o mecanum_demo
./mecanum_demo
```

Windows PowerShell에서는 실행 명령을 다음처럼 사용한다.

```powershell
.\mecanum_demo.exe
```

## 원본 코드에서 정리한 부분

- 비표준 매크로 M_PI 대신 constexpr PI를 사용했다.
- using namespace std 대신 std::를 명시했다.
- 단위와 좌표계를 주석으로 표시했다.
- 출력은 소수점 셋째 자리까지 표시한다.
- 계산식과 입력값은 원본을 유지했다.

## 직접 해 볼 실습

1. vy = 0, wz = 0: 네 바퀴의 RPM이 모두 같아지는지 확인한다.
2. vx = 0, wz = 0, vy > 0: FL/RR은 음수, FR/RL은 양수인지 확인한다.
3. vx = 0, vy = 0, wz > 0: 왼쪽 바퀴는 음수, 오른쪽 바퀴는 양수인지 확인한다.
4. 다른 값은 유지하고 r을 두 배로 늘리면 각 RPM이 절반이 되는지 확인한다.
5. Lx 또는 Ly를 바꿨을 때 순수 전진과 순수 회전에 미치는 영향을 비교한다.

## 실제 AGV로 확장할 때

목표 RPM을 모터 드라이버로 전달하고 엔코더 피드백으로 속도를 조절하는 단계가 필요하다.
기어 감속기가 있다면 바퀴 RPM과 모터 RPM을 구분해야 한다.
최대 RPM을 넘는 명령에는 네 바퀴를 같은 비율로 축소하는 등의 제한도 필요하다.
